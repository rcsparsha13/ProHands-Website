# ProHands – Worker Service Platform

## 📌 About the Project

**ProHands** is a web-based platform designed to connect users with workers and make it easier to search for workers, access worker information, and provide ratings for services.

The project provides separate interfaces for users and workers, helping make the process of finding and managing worker services more convenient.

## 🎯 Objectives

- Provide a platform for users to search for workers.
- Display search results to help users find suitable workers.
- Allow users to rate workers based on their services.
- Provide a dashboard for workers.
- Support worker registration and setup.
- Provide a login interface for accessing the platform.

## ✨ Features

- **Home Page:** Main interface for the platform.
- **User Login:** Login interface for users.
- **Worker Search:** Search for available workers.
- **Search Results:** Display worker search results.
- **Worker Ratings:** Interface for rating workers.
- **Worker Dashboard:** Dashboard for workers.
- **Worker Setup:** Interface for worker setup.

## 🛠️ Technologies Used

- **Python** – Backend application.
- **HTML** – Website structure and templates.
- **PostgreSQL** – Database.
- **Jinja2** – Template rendering.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd ProHands-Website
   ```

3. Install the required Python packages using your project's dependency list.

4. Configure the PostgreSQL database connection using your local database settings and environment variables.

5. Start the application:

   ```bash
   python app.py
   ```

6. Open the local URL displayed in the terminal in your web browser.
